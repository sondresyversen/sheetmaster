# SheetMaster 🎵

SheetMaster is an interactive UI/UX mobile application prototype designed for sheet music learning. The project focuses on user-centric design principles, intuitive navigation for musicians, and an aesthetic interface that balances usability with modern design trends.

### Features
- **Interactive Prototyping:** Fully interactive user flows allowing users to navigate between menus, song libraries, and learning modules.
- **Micro-interactions:** Custom transitions and button states designed to enhance the overall user experience (UX).
- **Tailored for Musicians:** Clean, high-contrast layouts designed specifically for easy reading while practicing instruments.

### Design Tools Used
- Adobe XD (UI/UX Design & Prototyping)

### Design & User Flow
1. **Onboarding & Dashboard:** Quick access to recent sheet music, daily practice goals, and progress tracking.
2. **Music Library:** A structured categorization system for finding sheets based on difficulty, genre, or instrument.
3. **Interactive Player:** A clean viewport designed for displaying sheets with playback tools and metronome integration.
